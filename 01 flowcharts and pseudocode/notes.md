# Day 01 – Flowcharts & Pseudocode

## What I Learned

- Flowcharts are visual representations of program logic.
- They help in understanding the flow before writing code.
- Pseudocode is a language-independent way to describe algorithms.

## Flowchart Basics

- Oval: Start / End
- Parallelogram: Input / Output
- Rectangle: Process
- Diamond: Decision
- Arrows: Flow direction

## Pseudocode Rules

- No strict syntax
- Focus on logic, not language
- Easy to convert into actual code

## Why This Matters

- Helps break down problems logically
- Reduces errors before coding
- Improves problem-solving clarity

## Example

Pseudocode to check if a number is even:

START  
Input number  
IF number % 2 == 0  
 Print "Even"  
ELSE  
 Print "Odd"  
END
